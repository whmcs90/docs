Welcome to the Wachat API. Use it to send messages, manage connected WhatsApp devices, work with contacts and templates, and receive webhook events from your workspace.

Authenticate every request with your workspace API token:

```http
Authorization: Bearer YOUR_API_TOKEN
```

For message requests, use the `device_id` returned by `GET /devices`.
## Base URL

All API requests should be made to the following base URL:

```bash
https://crm.wachat.net/api/v1
```
